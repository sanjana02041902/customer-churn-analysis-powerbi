Customer Churn Analysis Dashboard | Power BI & SQL
Project Overview

This project analyzes customer behavior, churn patterns, and retention opportunities for a banking organization. The objective is to identify factors influencing customer churn and provide actionable insights to improve customer retention and business performance.

The analysis was performed using SQL for data exploration and Power BI for data modeling, visualization, and dashboard development.

Business Problem

Customer churn is a major challenge for banks as it directly impacts revenue and customer lifetime value. This project aims to:

Understand customer demographics and behavior
Identify key churn drivers
Analyze customer activity and financial patterns
Support data-driven retention strategies

Key Insights
Geography Analysis
Germany shows the highest customer churn rate.
France and Spain demonstrate better customer retention.
Age Analysis
Customers aged 20–40 hold the highest balances.
The 30–40 age group presents both high value and high churn risk.
Product Analysis
Most customers use only 1–2 products.
Significant opportunities exist for cross-selling additional banking products.
Financial Analysis
Salary has a weak correlation with account balance.
Customer value is influenced more by tenure and product usage.
Business Recommendations
Implement targeted retention strategies for high-risk regions.
Increase engagement among inactive customers.
Promote product bundling and cross-selling initiatives.
Monitor churn trends regularly using dashboard insights.
