**Customer Churn Analysis Dashboard | Power BI & SQL**


📌 **Project Overview**

This project analyzes customer behavior, churn patterns, and retention opportunities for a banking organization. The objective is to identify factors influencing customer churn and provide actionable insights to improve customer retention and business performance.
The analysis was performed using SQL for data exploration and Power BI for data modeling, visualization, and dashboard development.

🚀**Business Problem**
Customer churn is a major challenge for banks as it directly impacts revenue and customer lifetime value. This project aims to:
1. Understand customer demographics and behavior
2. Identify key churn drivers
3. Analyze customer activity and financial patterns
4. Support data-driven retention strategies

📈**Key Insights**

**Geography Analysis**
1. Germany shows the highest customer churn rate.
2. France and Spain demonstrate better customer retention.

**Age Analysis**
1. Customers aged 20–40 hold the highest balances.
2. The 30–40 age group presents both high value and high churn risk.

**Product Analysis**
1. Most customers use only 1–2 products.
2. Significant opportunities exist for cross-selling additional banking products.

**Financial Analysis**
1. Salary has a weak correlation with account balance.
2. Customer value is influenced more by tenure and product usage.


**Business Recommendations**
1. Implement targeted retention strategies for high-risk regions.
2. Increase engagement among inactive customers.
3. Promote product bundling and cross-selling initiatives.
4. Monitor churn trends regularly using dashboard insights.
